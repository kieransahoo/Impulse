# CreatorBrain + Impulse

## Vision

CreatorBrain is an AI‑powered personal memory that transforms saved internet content into structured knowledge.

Impulse is the intelligence layer that retrieves relevant memories and generates personalized recommendations based on the user's current context.

**Flow**: Save → Understand → Remember → Retrieve → Recommend

## Problem

People save hundreds of useful links, Reels, Shorts, blogs and product pages, but later struggle to find or use them when making decisions.

- Bookmarks only store URLs.
- CreatorBrain stores knowledge.

## MVP Goal

Build an AI‑powered second brain that allows users to:

- Save useful internet content
- Convert it into structured memory
- Search personal knowledge
- Ask AI questions
- Receive personalized recommendations

## Supported Content

**Included**
- Web Articles
- Blogs
- Product Pages
- Places (Restaurants, Cafes, Travel)
- YouTube Shorts (URL)
- Instagram Reel Links
- Manual Notes

**Not Included**
- Auto watch history
- Instagram scraping
- PDF
- Images
- Voice
- Mobile App
